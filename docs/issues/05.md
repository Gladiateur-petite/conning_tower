# HPのSAFE/DANGER/UNKNOWNと世代・鮮度を導入する

計画ID：05（GitHub番号ではない）
推奨branch：`feature/hp-validity`
依存計画ID：04

## Background

現行の空データreturn/例外にはHP専用の有効性がない。

## Requirement

純粋Safety判定、フィールド鮮度、出撃/戦闘世代、Failure理由を導入する。

## Acceptance Criteria

- [ ] UNKNOWNはSAFEへ変換されず、既知大破と不明艦を同時表示できる結果構造を持つ。
- [ ] diff reviewとPRに根拠・検証結果・未対応を記録する。

## Safety considerations

キャッシュ/古いHP、確認ボタン、経過時間はSAFEの根拠にしない。

## Test cases

25/100境界、0、MaxHP0、null/負/超過、cache、旧世代、混在DANGER+UNKNOWN。

人間レビュー：仕様解釈と期待値、変更対象、失敗時の扱い、実行結果を確認する。
