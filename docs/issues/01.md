# Flutter 3.35.1の基準テストと外部設定なしの開発境界

計画ID：01（GitHub番号ではない）
推奨branch：`chore/dev-baseline`
依存計画ID：00

## Background

現行mainはFirebase設定とnative副作用に依存し、新Forkの再現を妨げる。

## Requirement

SDK/lockを固定し、テストのtelemetry/保存/通知を注入・mock可能にする。CIをPRで実行可能にする。

## Acceptance Criteria

- [ ] Windowsでpub get・生成・battle test・analyze・全testの結果を記録する。基準失敗を識別し、必須core testを再現する。
- [ ] diff reviewとPRに根拠・検証結果・未対応を記録する。

## Safety considerations

Crashlyticsへ実API/tokenを無条件送信しない。ゲーム通信/自動操作はCIで使わない。

## Test cases

外部Firebaseなしのunit/widget test、telemetry無効起動、設定欠落時の明示エラー。

人間レビュー：仕様解釈と期待値、変更対象、失敗時の扱い、実行結果を確認する。
