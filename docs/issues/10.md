# 大破/判定不能の持続Overlayを既存UIへ追加する

計画ID：10（GitHub番号ではない）
推奨branch：`feature/persistent-safety`
依存計画ID：06,09

## Background

現行Toastと確認dialogだけではHP/MaxHPとUNKNOWNの継続表示を満たさない。

## Requirement

rootにDANGER/UNKNOWN表示を置く。Toast/dialogは補助。確認操作は表示縮小だけにする。

## Acceptance Criteria

- [ ] 艦名・HP/MaxHP/不明理由が読み取れ、時間/遷移/回転/ackで状態が消えない。
- [ ] diff reviewとPRに根拠・検証結果・未対応を記録する。

## Safety considerations

ゲームAPI・進撃操作へ介入しない。Overlayが誤タップを起こさない。

## Test cases

時間経過、screen/tab/route、文字拡大、複数艦、既知大破+不明、iOS実機。

人間レビュー：仕様解釈と期待値、変更対象、失敗時の扱い、実行結果を確認する。
