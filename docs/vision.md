# Vision

本プロジェクトはEOの完全移植ではなく、iPhone/iPadで頻繁に使う機能に絞った軽量な艦これ支援ブラウザを作る。ConningTowerの画面構造・ブラウザ基盤を維持し、各艦や艦隊の必要な情報を少ない操作で読めるようにする。

P0：大破警告、cond、艦隊合計、制空、出撃中燃料/弾薬%。P1：33式索敵、ボス残りゲージ。遠征は攻略Wikiと照合する集計を表示し、成功条件の完全自動判定DBは作らない。

同時に、AI駆動開発とGitHub運用を実践的に学ぶ。成果はIssue・仕様・テスト・差分・PR・設計判断に残す。AIconのケーススタディでは、AIに任せた範囲、人間が変えた判断、テストで見つかった問題、時間を短く記録する。

ゲームAPIの変更・自動進撃・自動周回・操作代行は対象外。読み取り情報を表示する。SAFEは限定的なHP判定の状態名であり、ゲーム進撃を推奨/保証する表現にしない。UNKNOWNをSAFEに変換しない。

初版の成功条件：各P0機能の仕様と制限が明確、サポート戦闘形式のfixture→HP→判定が再現可能、未対応形式/通信欠落はUNKNOWN、警告の持続が実機で確認できること。スコープ追加は実際に使って不足を認識したときにIssueへ起こす。
